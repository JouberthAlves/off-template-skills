# Brief: the Super-Webdesigner site, second version

The page that sells the project, redone through the flow as the skill's own
test: the lint runs on the old page and on the new one. The old version
(2026-10-20, "Red Pencil Proof") is in `archive-2026-10-20/` and is evidence,
not a base: its whole combination (reference + feeling + collision) does not
come back.

**Baseline of the old page (sloplint, 2026-10-26):** 22 FAIL (21 colours
outside tokens, a sideways scroll at 1280 px from the crop marks), 5 WARN
(mono labels, 949 words, 94 words on the first screen, no clip, no stamp).

**Mode:** Persuade.

**Who it's for:** developers and designers who build with coding agents
(Claude Code, Codex, Cursor) and are tired of every page looking the same.
They land from GitHub or a post and decide in seconds. Who pays: nobody, it's
MIT; what they spend is attention and a line in their terminal.

**Job:** copy the install command. A GitHub star is the second action.

## The 4 questions (answered by the owner, 2026-10-26)

1. **Real-world object:** the code editor with the agent running, at night.
2. **Feeling in the first 3 seconds:** pride: "my pages are going to look
   like this".
3. **Influences:** the sites of web technologies (Stripe, Vercel, Linear and
   their peers). Read as: the polish and life of the best dev-tool sites,
   colliding with the editor at night; the directions name the second
   influence each one brings.
4. **Must never look like:** a docs site or a SaaS template; a brutalist spec
   sheet (mono labels, black boxes); an AI-made page (purple, cards, emoji).

**Motion:** Stripe as the reference (the flowing beams of light, alive and
polished), lively intensity. The beams' colours still come from question 1
(the editor's own light), not from Stripe's palette, and never purple to blue
(question 4).

## Material

- **Real:** the two example runs (burger, ai-notes) with screenshots and
  mockups; the 13 tells; the flow; the install commands per agent; the lint
  result (the flow's burger page 12 FAIL against the plain agent's 39).
- **Absent:** user counts, testimonials, company logos, star counts. None of
  them goes on the page.

**Name, logo and favicon:** Super-Webdesigner; logo and favicon required in
every direction.
