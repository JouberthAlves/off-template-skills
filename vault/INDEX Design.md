# INDEX Design

Everything about creating and reviewing sites, pages and UI. You get here from
[[INDEX]].

## Required: no step can be skipped

Applies to every site or page, even with a detailed request, even if the vault
was read at the start of the session. If a step can't be done, say which one
and why. Never skip in silence.

1. Read [[Agent rules]] and [[Design rules]].
2. Read [[AI design patterns to avoid]].
3. Read [[Styles]] (the niche note, if it exists) and every note in
   `20 Projects/` (list below), plus any report the person attached, **in
   full**, including the visual part.
4. Discover the tools you have: [[Capabilities]].
5. Ask the 4 questions of the [[Design brief]].
6. Research real sites in the niche: [[Research real sites]].
7. Show 3 directions and wait for the choice: [[Skeletons before code]].
8. Before any paid or media tool, read [[Tool usage]].
9. Write the chosen direction down (`design/direction.md` in the project).
10. Build.
11. Before delivering: screenshots at desktop and 390 px, run
    [[AI design patterns to avoid]] on them and say what still shows up; run a
    design critique and fix what it points out; run the review battery
    (`skills/off-template/references/review.md` in the off-template repo).
12. Create the note in `20 Projects/` from [[_template]] and add a row to the
    table below.
