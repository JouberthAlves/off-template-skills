# AI design patterns to avoid

The habits an agent repeats when it decides alone. Each one, on its own, looks
like a choice; together they are the signature of "a page made by AI". Applies
to landing pages, sites, apps and any visual piece.

Read before choosing a direction and again when reviewing the first version.

| Pattern | Why avoid it | Instead |
|---|---|---|
| **Purple or blue gradient** | The number one marker of a generated page | Color taken from the project's real reference (brief question 1). Gradient only if the reference calls for it, and never purple to blue |
| **Default type** | Serif italic became every AI's shortcut for "elegant"; Inter, Space Grotesk, Plus Jakarta Sans, DM Sans and Roboto are its shortcut for "clean" | A face chosen for a reason that comes from the reference: a sans with character, a display face, condensed, or hand-lettering. Write the reason down |
| **Grid background** (squares, dots, lines) | Filler to hide emptiness; on almost every "tech" template | Texture, photo, flat color or deliberate empty space |
| **3 generic benefit cards** | Icon + title + two lines, three times, side by side: the most copied block on the web | The benefit inside proof (photo, number, before/after), an asymmetric list, one big benefit and the rest smaller |
| **Emoji in the copy** | Cheapens the text and gives away generated copy | None. If a visual marker is needed, use an icon from the page's own system |
| **Glow on everything** (text, buttons, borders) | Everything glowing means nothing stands out | Contrast of color and size. If there's an effect, on **one** element only |
| **The usual layout** | Centered hero → 3 cards → testimonials → FAQ → CTA: the spine of every AI page | No need to reinvent the wheel every time, but break at least the order or the composition: asymmetric hero, a section that bleeds into the next, a rhythm of different sizes |
| **Generic icons** | Thin-line Lucide/Feather are the invisible default | An icon drawn for the project, a cut-out photo, or less-used families (Phosphor, Solar) with a chosen weight |
| **Everything static** | A still page looks like a mockup, not a product | Motion with a purpose: scroll entrances, hover that responds, one live element in the hero. Respect `prefers-reduced-motion` |
| **01 / 02 / 03 on an unordered list** | The number suggests a sequence. On loose items (services, benefits) it's decoration that implies steps that don't exist | Number only when order matters (steps, stages, timeline). Loose lists go without numbers |
| **Hard shadows and boxes everywhere** (neo-brutalism) | Offset shadows with no blur, thick black outlines, square corners on every block, buttons that "press" into their shadow. The agent's escape from the purple gradient; it reads as a tool whatever the business is | Edges and depth by role and by the reference's material: a border or shadow only on the one element that must stand apart, a radius that matches the real objects, shadow only where the light is real |
| **Spec-sheet dressing** | Monospace in nav, buttons and labels; lot numbers, temperatures, coordinates, barcodes, "status: live" bars, countdowns nobody asked for | Only the data the visitor acts on (hours, price, pickup), in the page's own text face. Mono only for real code or tables |
| **A default AI look** | The second set of defaults: warm cream + terracotta (often with a serif), near-black + one acid-green or vermilion pop, the newspaper broadsheet, receipts/tickets/stamps as the concept | The look comes from the brief's own object and feeling. Any of these only when brief question 1 named it, and never in more than one of the three directions |

Plus the **niche list** from [[Research real sites]]: the look everyone in this niche
already repeats.

## Running from generic is not the goal

An agent that avoids every tell and every niche cliché can make a page that no
longer looks like the business (grey cement and mono labels for a barbershop,
a technical spec sheet for a bakery). Keep what visitors of the niche expect;
originality goes on top of it.

- **3-second test:** would a customer of this niche know what the business is,
  and want it, from the first screen alone?
- **Fit test:** do the edges, shadows, lines, texture, type and motion match
  the feeling from the brief? (`references/visual-language.md` in the
  off-template skill.)

## How to check

Run the list on full-page screenshots of the finished page (desktop and
390 px) and on its source, never on the first screen alone; and on each
mockup.
Write down each item: absent, present, or present on purpose (with the reason
from the brief). **Three or more present means the page still looks AI-made:
go back to the brief, don't just swap colors.** Either fit test failing sends
the direction back too.
